# Fatigue & Distraction Detection System
**ENSIA x Qareeb - Industrial Project**

Real-time driver monitoring using a single in-vehicle camera on Raspberry Pi 4.

## Modules
- Face Mesh & Head Pose
- Geometric Fatigue (EAR / MAR / PERCLOS)
- Gaze Estimation
- Deep Learning Fatigue (conditional)
- Compliance Detection (seatbelt, phone, smoking)
- Integration Pipeline

## Setup
`
pip install -r requirements.txt
`

## Run demo
`
python scripts/run_demo.py
`
